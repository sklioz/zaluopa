# Еда без паники — сайт-памятка для студентов ТОГУ

Многостраничный адаптивный сайт по теме студенческого питания. Проект ориентирован на аудиторию 17–23 лет, ограниченный бюджет, нехватку времени и условия общежития — в соответствии с исходным проектным документом.

## Страницы
- `index.html` — главная с визуальной концепцией и переходами.
- `guide.html` — базовые ориентиры, корзина, питание без полноценной кухни, привычки.
- `recipes.html` — каталог рецептов, фильтры, поиск и карточки с подробностями.
- `planner.html` — примерное меню на неделю, условия кухни, список покупок, копирование списка.
- `quiz.html` — интерактивный тест с результатом.
- `profile.html` — локальная сводка прогресса.

## Публикация на GitHub Pages
1. Создайте репозиторий на GitHub.
2. Загрузите **все файлы из этой папки** в корень репозитория.
3. Откройте `Settings → Pages`.
4. В разделе Build and deployment выберите `Deploy from a branch`, ветку `main`, папку `/(root)`, нажмите `Save`.
5. Через некоторое время GitHub покажет адрес опубликованного сайта.

## Важно
- План, отметки, список покупок и результат теста хранятся в `localStorage` текущего браузера.
- Общего аккаунта, облачной базы и общего форума в этой версии нет: для синхронизации между людьми и устройствами нужен backend.
- Service worker позволяет кешировать основные страницы после первого посещения, если сайт опубликован через HTTPS.
- Внешний шрифт подключается через Google Fonts; при отсутствии интернета используются запасные системные шрифты.
- Содержание представляет собой общий образовательный материал, а не лечебные рекомендации. Примеры меню и рецептов не учитывают индивидуальные заболевания, аллергии и назначения врача.
