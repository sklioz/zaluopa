# Тарелка

Адаптивный многостраничный сайт с подбором рецептов, пятью тестами, недельным планом и локальной корзиной продуктов.

## Страницы
- `index.html` — главная.
- `recipes.html` — подбор рецепта по времени, бюджету, кухонным условиям и исключённым продуктам. Есть дополнительные пометки для диабета и особенностей ЖКТ, но они не являются медицинской фильтрацией.
- `guide.html` — общие ориентиры, магазин, кухня и привычки.
- `planner.html` — меню на неделю и перенос покупок в корзину.
- `quiz.html` — пять отдельных тестов.
- `basket.html` — локальная корзина, количество, отметки и копирование списка; ссылка на официальный каталог «Пятёрочки».
- `profile.html` — локальный прогресс.

## Публикация
Загрузи все файлы из этой папки в корень GitHub-репозитория. В GitHub открой Settings → Pages → Deploy from a branch → `main` → `/(root)` → Save.

## Ограничения
- Список покупок и настройки сохраняются только в `localStorage` текущего браузера.
- Корзина не связана с аккаунтом магазина и сама не добавляет товары в заказ. Кнопка ведёт в официальный каталог: https://5ka.ru/catalog/ . Наличие, цены и доставка зависят от выбранного региона и магазина.
- Профили «диабет» и «ЖКТ» не рассчитывают углеводы, не диагностируют и не определяют лечебную пригодность рецептов. Фильтры для продуктов без лактозы/глютена не проверяют состав на производстве; упаковку и аллергены нужно проверять самостоятельно.
- Фильтры подбора обрабатываются в браузере; медицинский профиль не отправляется на сервер.
